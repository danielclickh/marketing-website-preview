Database engines allow you to work with tables.

By default, ClickHouse uses database engine [Atomic](../../engines/database-engines/atomic). It provides configurable [table engines](../../engines/table-engines/index) and an [SQL dialect](../../sql-reference/syntax).

You can also use the following database engines:

-   [MySQL](../../engines/database-engines/mysql)

-   [MaterializedMySQL](../../engines/database-engines/materialized-mysql)

-   [Lazy](../../engines/database-engines/lazy)

-   [Atomic](../../engines/database-engines/atomic)

-   [PostgreSQL](../../engines/database-engines/postgresql)

-   [Replicated](../../engines/database-engines/replicated)

-   [SQLite](../../engines/database-engines/sqlite)
